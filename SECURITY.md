# Политика безопасности (Security Policy)

Я серьезно отношусь к безопасности своего проекта. Если вы обнаружили уязвимость, пожалуйста, ознакомьтесь с руководством ниже, чтобы сообщить мне о ней безопасным способом.

## 🛡️ Поддерживаемые версии

Я выпускаю исправления безопасности (security patches) только для указанных ниже версий проекта:

| Версия | Поддерживается |
| :----- | :------------: |
| < 1.0  |     ✅ Да      |

## ✉️ Как сообщить об уязвимости

> ⚠️ **ВАЖНО:** Пожалуйста, **НЕ создавайте публичные Issues** на GitHub для сообщений об ошибках безопасности. Это может подвергнуть риску пользователей проекта до того, как мы успеем выпустить патч.

Если вы нашли проблему с безопасностью:

1. **Способ 1 (Рекомендуемый):** Используйте встроенный инструмент GitHub [Private Vulnerability Reporting](https://github.com). Перейдите во вкладку **Security** -> **Advisories** в этом репозитории и нажмите **Report a vulnerability**.

### Что указать в отчете:

- Подробное описание уязвимости.
- Шаги для ее воспроизведения (желательно с примером кода / PoC).
- Возможные последствия (какие данные могут пострадать).

## 🕒 Чего ожидать дальше

- Мы подтвердим получение вашего отчета в течение **48 часов**.
- Мы сообщим вам о ходе анализа уязвимости и скоординируем с вами дату публикации исправления.
- Если уязвимость подтвердится, мы упомянем вас в списке благодарностей в Changelog (по вашему желанию).
