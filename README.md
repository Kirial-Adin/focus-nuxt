# Focus App — Frontend

Приложение для фокусировки и продуктивности.

## ✨ Features

- Личный и групповой Pomodoro-таймер
- Рабочие группы + чат
- Реакции на сообщения (мульти-реакции)
- Роли пользователей

## 🛠 Stack

Nuxt 4, TypeScript, Pinia

## 🚀 Getting started

cp .env.example .env
pnpm install
pnpm dev
